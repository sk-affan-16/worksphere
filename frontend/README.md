# WorkSphere Frontend

Angular frontend for the **WorkSphere — Multi-Tenant Enterprise SaaS Platform for Workforce & Workflow Management**.

The frontend provides the user interface for authentication, dashboard, organization, employees, onboarding, documents, tasks, workflow, and notifications.

> **Current status:** Feature pages currently use frontend demo data where backend API contracts are not yet integrated. Real authentication and backend API integration will be connected after the corresponding backend contracts are confirmed.

## Technology

- Angular 22
- TypeScript
- Angular Router
- Angular Reactive Forms
- RxJS
- Vitest
- HTML
- CSS
